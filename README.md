# zomboid_mic_toggle

Project Zomboid **Build 42 멀티플레이**용 마이크 토글 모드입니다.

- **T 한 번:** 마이크 켜기. 키를 놓아도 말할 수 있습니다.
- **T 다시 한 번:** 마이크 끄기. 다른 플레이어의 음성은 계속 들립니다.
- 접속할 때는 마이크가 꺼진 상태로 시작합니다.
- 화면 위쪽에 마이크 상태가 표시됩니다.
- 채팅·텍스트 입력 중에는 T를 입력해도 마이크 상태가 바뀌지 않습니다.
- 일반 플레이 중 T는 마이크 토글에 사용합니다. **Enter로 채팅창**을 여세요.
- 키를 길게 눌러도 한 번만 전환됩니다. 사망 시에는 자동으로 음소거됩니다.

켜짐 상태는 게임의 **음성 감지(VAD)** 송신 모드를 사용합니다. 실제 목소리가 감지될 때 송신하므로 키를 누르고 있을 필요가 없습니다. 꺼짐 상태는 **듣기 전용** 모드입니다.

## 설치

1. 배포 ZIP 안의 `zomboid_mic_toggle` 폴더를 서버와 접속자 PC의 `Zomboid/mods/`에 복사합니다. 소스 코드를 받았다면 `mod/zomboid_mic_toggle` 폴더를 복사하세요.
2. 서버 설정의 `Mods=` 목록에 `zomboid_mic_toggle`을 추가하고 서버를 재시작합니다.
3. 게임의 **설정 → 소리 → 음성 채팅**을 활성화하고 사용할 마이크를 선택합니다. 서버의 `VoiceEnable=true`도 필요합니다.
4. 서버에 접속한 뒤 **T**로 켜고 끕니다.

`Zomboid`는 게임 실행 계정의 홈 폴더 아래에 있습니다. `-cachedir`를 사용하면 해당 경로입니다. 다른 모드나 별도 실행 프로그램은 필요 없습니다. Steam Workshop 등록용 ID는 포함하지 않습니다.

## 개발 및 검사

Build 42.21.0에서 실제 키 입력과 상태 전환을 확인했습니다. 같은 PC의 게임 클라이언트 2개를 서버에 연결해 **실제 마이크 음성의 양방향 송수신, T로 송신 차단·재개, 내 마이크가 꺼진 상태에서 상대 음성 수신**까지 확인했습니다. 자동 검사 10개도 통과했습니다. 측정값과 확인 범위는 [TESTING.md](TESTING.md)를 참고하세요.

게임 실행에는 Python이 필요 없습니다. 아래 명령은 개발용 Lua 시뮬레이션 검사와 배포 ZIP 생성에 사용합니다.

```sh
python -m pip install -r requirements-dev.txt
python -m unittest discover -s tests -v
python tools/package.py
```

배포 파일은 `dist/zomboid_mic_toggle.zip`에 생성됩니다. 게임 코드·게임 파일·테스트용 서버 데이터는 저장소나 배포 파일에 포함하지 않습니다.
